# ReStore 高保真可交互 UI 原型（PROTOTYPE — #37）

> **PROTOTYPE — Throwaway UI Prototype for [#37](https://github.com/penguinyzsh/restore/issues/37)**
> 本目录遵循 `prototype` 规范保存在独立分支 `prototype/restore-ui-37` 上，已收敛采用 **Apple Bento 空间矩阵 × PlayStation 5 常驻控制坞（B 方案）**，并完成细节打磨。

## 一键运行

在仓库根目录执行：

```sh
python3 -m http.server 8788 --bind 127.0.0.1 --directory prototype/ui-37
```

## 核心视觉与交互约束

- **右上角状态胶囊**：仅展示当前时间与标准几何用户图标（`ICONS.user`）。
- **上中概览展示区**：纯环境信息展示（PS5 内置存储光谱、守护状态与最近恢复点、三大存储位置环形容量与在线/同步状态），无交互焦点。
- **底部常驻四纯 ICON 卡片**：依次为 **恢复、软件、商店、其他**，卡片内部仅含立体图形图标；进入子页面时自动收窄常驻底部并支持 FLIP 动画过渡。
- **恢复页 2×3 横向卡片**：采用一行两个、共三行的从上到下布局（第 1～5 张为恢复对象横向卡，第 6 张为右下角「开始整机恢复」汇总执行主卡）。
- **首次引导分步向导**：拆分为「1. 选择存储位置 → 2. 选择恢复点 / 备份范围 → 3. 确认并执行」三步单屏向导，支持点击步骤条、「上一步 / 下一步」及手柄 `◯ 返回` 逐级回退。
- **全站统一大圆角**：所有主卡片统一使用 `--radius-card: 30rem`（外层控制坞采用同心曲率 `44rem`，内嵌行采用 `20rem`）。
- **右下角手柄按钮栏**：固定为 `✕ 确认`、`◯ 返回`、`△ 备份`、`□ 恢复`。
