# ReStore 高保真可交互 UI 原型（PROTOTYPE — #37 / #45）

> **PROTOTYPE — Throwaway UI Prototype for [ReStore 本机界面各页面的粗框架结构如何排布](https://github.com/penguinyzsh/restore/issues/45) & [交付融合 ReStore 官方 Logo 的高保真可交互 UI 原型（含商店锁定遮罩外观）](https://github.com/penguinyzsh/restore/issues/37)**
> 本目录遵循 `prototype` 规范保存在独立分支 `prototype/restore-ui-37` 上，采用 **Apple Bento 空间矩阵 × PlayStation 5 常驻双图标控制坞（恢复、其他）** 融合方案。
> **第二阶段页面归档说明**：「软件（`?view=apps`）」「商店（`?view=store`）」「搜索（`?view=search`）」完整可交互版本已归档保存在提交 [`4f9954b`](https://github.com/penguinyzsh/restore/commit/4f9954b)，待第二阶段开发商店与搜索功能时直接调取启用。

## 一键运行

在仓库根目录执行（推荐使用支持 HTTP/1.1 Keep-Alive 与高并发队列的启动命令）：

```sh
python3 -c '
import functools, http.server
class H(http.server.SimpleHTTPRequestHandler):
    protocol_version = "HTTP/1.1"
class S(http.server.ThreadingHTTPServer):
    request_queue_size = 128
    allow_reuse_address = True
handler = functools.partial(H, directory="prototype/ui-37")
S(("127.0.0.1", 8788), handler).serve_forever()
'
```

## 当前已锁定的粗框架与交互结构（第一阶段：备份与恢复）

- **顶部状态栏**：左侧仅展示当前页面大标题（无返回按钮，统一通过手柄 `◯ 返回` 回退），右侧状态胶囊仅展示当前时间与标准几何用户图标（`ICONS.user`）。
- **主界面上中概览展示区**：纯环境信息展示（左卡：最近恢复点与 5 类受保护对象状态；右卡：三大存储位置环形容量与在线/同步状态），无卡片内按钮、无状态圆点、无小标题徽章。
- **底部常驻单排双纯 ICON 控制坞**：单排 2 列（`repeat(2, minmax(0, 1fr))`），从左到右依次为 **恢复、其他**；进入子页面时自动收窄常驻底部并支持 FLIP 动画过渡。（第二阶段「软件、商店、搜索」可交互原型已归档于提交 `4f9954b`。）
- **恢复页（全程无二级弹窗、无独立二级锁屏页，统一融于 2×3 矩阵）**：
  - 常态下前 5 张为 5 类核心备份恢复对象卡，第 6 张为「恢复源与执行总控」卡；
  - 恢复执行中与恢复完成汇总均直接在同一个 `2×3` 网格内原地切换呈现，底部辅以无卡片底框的单行温和警告条。
- **其他（设置）页左导右景舞台**：左侧为 4 项毛玻璃导航轨（存储位置与连接、自动备份内容范围、恢复点保护与清理、后台守护与引导向导），右侧为聚焦大舞台，结合 Apple 拨杆开关与环形容量环。
- **首次引导分步向导**：拆分为「1. 选择存储位置 → 2. 选择恢复点 / 备份范围 → 3. 确认并执行」三步单屏向导。
- **全站统一大圆角与底部按键提示**：所有主卡片统一使用 `--radius-card: 30rem`；右下角手柄按钮栏固定为 `✕ 确认`、`◯ 返回`、`△ 备份`、`□ 恢复`；左下角提供可一键收起/展开的 `DEV 场景调试` 胶囊。
