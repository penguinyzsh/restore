# ReStore 高保真可交互 UI 原型（PROTOTYPE — #37）

> **PROTOTYPE — Throwaway UI Prototype for [#37](https://github.com/penguinyzsh/restore/issues/37)**
> 本目录为遵循 `prototype` 规范保存在独立分支 `prototype/restore-ui-37` 上的第一阶段 UI 原型，采用已选定的 **PS5 控制中心极简横向带（Ribbon 大磁贴阵列 + 高密度设置工作台）** 方案，供后续阶段继续细化。

## 一键运行

在仓库根目录执行：

```sh
python3 -m http.server 8788 --bind 127.0.0.1 --directory prototype/ui-37
```

随后在浏览器打开：

- **概览页（开放式状态顶栏 + 4 张等高纵向磁贴阵列）**：<http://127.0.0.1:8788/?view=home>
- **恢复页（开放式位置/恢复点胶囊条 + 5 张纵向等高步骤卡片）**：<http://127.0.0.1:8788/?view=restore>
- **设置页（2×2 高密度四模块同屏工作台）**：<http://127.0.0.1:8788/?view=settings>
- **软件商店（灰置顶栏标签 + 底层卡片 + 顶层半透明预览锁定遮罩）**：<http://127.0.0.1:8788/?view=store-apps>
- **网盘游戏（灰置顶栏标签 + 底层封面网格 + 顶层半透明预览锁定遮罩）**：<http://127.0.0.1:8788/?view=store-games>
- **首次引导全屏覆盖层（含 WebDAV 手柄输入法弹窗与有/无恢复点双分支）**：<http://127.0.0.1:8788/?view=onboarding>
- **应用内全屏专注恢复进度锁（含温和提示、游戏运行冲突检测、断电重启断点续做）**：<http://127.0.0.1:8788/?lock=resumed>

> **开发者原型调试悬浮窗**：页面左下角独立悬浮 `PROTOTYPE DEV（仅原型调试悬浮窗）`，支持一键收起/展开，并可在不污染正式产品 UI 的前提下切换首次引导双分支、恢复进度锁三种状态及空间不足告警预览。

## 键盘 / 手柄快捷键

- `↑` `↓` `←` `→`：十字键空间焦点高亮流转
- `Q` / `E`：模拟手柄 `L1` / `R1` 顶部页面切换（页面内点击绝不意外跨页跳转）
- `Enter`：模拟 `✕ 确认`
- `Esc` / `Backspace`：模拟 `◯ 返回`
- `T`：模拟 `△ 立即备份`
- `F`：模拟 `□ 锁定恢复点`
