# 问题分类标签

| 分类角色 | 本项目标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者提供信息 |
| `ready-for-agent` | `ready-for-agent` | 规格清晰，可交由代理执行 |
| `ready-for-human` | `ready-for-human` | 需要由人执行 |
| `wontfix` | `wontfix` | 不予处理 |

技能提到分类角色时，使用表中的项目标签。
